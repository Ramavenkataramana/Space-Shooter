# 🚀 Space Shooter Game

A classic 2D space shooter built with **Python** and **Pygame**.  
The player controls a spaceship, dodges enemy fire, and destroys incoming alien ships to earn points.

---

## 🎮 Features
- Player spaceship with movement controls (arrow keys / WASD).
- Shooting mechanics with bullets.
- Enemy ships that spawn and move downward.
- Collision detection between bullets and enemies.
- Score tracking and game over screen.
- Background music and sound effects.

---

## 🛠 Requirements
- Python 3.x
- Pygame library
